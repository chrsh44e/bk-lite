# 3.1.29 Release Notes
Release Date: May 22, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Added user actions: disable, enable, and unlock accounts after password retry limits are exceeded. |
| CMDB | Added collection task overview statistics to the auto-discovery page. |
| Monitoring | Added Huawei OceanStor storage monitoring. |
| Alert Center | Added ownership organization definitions for Event integrations. |

### Improvements

| Module | Improvements |
| --- | --- |
| Node Management | Fixed abnormal Windows controller installation issues. |
| CMDB | Optimized the K8s collection installation flow. |
| Monitoring | Fixed incorrect metric mapping in alert templates. |
| Alert Center | Optimized the alert integration page to improve the configuration experience. |
| Operations Analysis | Optimized the built-in CMDB and Alert Center analysis views. |
| OpsPilot | Optimized the visual experience for agent tool calls. |
